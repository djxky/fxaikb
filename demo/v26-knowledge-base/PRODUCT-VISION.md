# 飞象 AI 知识库 · 产品构想（PRODUCT VISION）

> 这份文档是产品的"宪法"。每次重大决策前先翻这份。  
> §3 红线不可违反（无论谁提的，违反则拒绝）。其他原则随时迭代，但要追加到 §9 决策日志。  
> 最后更新：2026-05-07（v3.4 — 最近对话按"是否有产物"分流：有产物 → 三栏文件居中 / 无产物 → 全屏对话）

---

## §1 · ONE-LINER

> **通用 AI 没读过你的备课资料；飞象读过。**

延伸：把老师手头散乱的 PPT / 教案 / 真题 / 错例 一次拖进来，飞象 AI 帮你结构化、关联、激活——生成的内容是基于你的资料、你能直接拿去上课的。

---

## §2 · 心智锚点（4 句话，墙上挂的那种）

1. 飞象 = 把老师手头的死文件，结构化成活的知识网络，AI 在网络上帮老师做事。
2. 通用 AI 是新来的实习生；飞象是了解你班级的老同事。
3. 老师 100% 主权——AI 给数据、不给指令。
4. **知识库不是给老师看的"知识地图"，而是给 AI 用的"调料柜"。** 老师只关心"端出来的菜"——出题 / 教案 / 课件 / 讲评，不关心"调料怎么排列"。

---

## §3 · 四条红线（不可违反）

> 锁死。每次提议如果违反，**无论谁提的都拒绝**。

1. **教师 100% 主权** — AI 不动原文件，AI 产物在对话上下文呈现，**老师手动「保存到我的知识库」才入库**（v3：删除"草稿"中间态，改为对话即记录）
2. **AI 不主动推送 / 不主动盘点** — 召唤式助手，不是 agent
   - 不出"建议你..."
   - **不主动给老师写"文件夹总结" / "wiki 主题页" / "知识地图"**（老师不需要被告知"你的资料长什么样"，她只需要 AI 能用这些资料帮她做事）
   - AI 所有"对话外的智能"都跑在后台，**老师感知不到，但用着觉得 AI 越来越懂我**
3. **知识库与外部数据严格分离** — "引用"，不"注入"
   - 知识库 = 老师**自己整理的资料**（PPT / 教案 / 真题 / 错例）
   - 学情 / 作文等其他飞象产品的数据 = AI 可"**引用**"的外部 sources，**不写入知识库**
   - 学校未买其他产品 → 知识库**完整可用**
   - 学校买了其他产品 → AI 可调用更广 context（**引用，非吞并**）
   - 这条同时保证了：知识库纯净 / 可独立售卖 / 跟 NotebookLM 的 sources 模型对齐
4. **知识库（文件） vs 题库（单题）边界清晰** — 不互相吞并
   - **知识库** = 文件层（PPT / Word / PDF / 试卷整卷 / 题单 / 图片 / 扫描件）
   - **题库** = 结构化单题层（题干 + 选项 + 答案 + 知识点 + 难度 + 题型 + 来源）
   - 老师上传含题文件 → 知识库收录文件 → 老师手动触发「AI 录入题库」→ 题目入题库
   - 题库与「飞象作业星 · 我的资源」是同一份数据（多入口、单数据源）
   - 题目不进 wiki / 不进知识库索引，AI 对话时通过 Function Call 召回

## §4 · 用户 / 场景 / 商业模型

### 用户与客户

- **客户**（付费方）：学校 / 教研组 / 区县（**当前在做的是企业版**）
- **用户**（使用方）：单个老师（v1 单老师视角，v2 加教研组协同）

### 4 个高频场景（v1 全部覆盖）

| 场景 | 典型问法 | 飞象产出 |
|---|---|---|
| **备课** | "把这份课件改成 8 年级难度，留 5 分钟做导入" | AI 在对话中给一版，老师可一键「保存到我的知识库」 |
| **出题** | "出 10 道二次函数题包含 a/b/c 判断" | AI 出题 + 答案，老师可一键入库 |
| **讲评 / 学情** | "找出八(3)班最近 3 次月考薄弱点" | AI 跨文件分析，给一份学情分析 |
| **检索** | "去年讲过的二次函数那张 PPT 在哪" | AI 直接定位 + 跳转原文件 |

### 商业模型

- **个人版**：免费（飞象 AI 基础版承担）
- **企业版**：学校 / 区县采购，按校 ¥3-10w/年（**这是当前设计的对象**）

**B 端付费驱动**（按重要性，待 v1 验证后调整）：
1. **教研组协同**（v2 主战场）— 共建知识库、共出题
2. **学情看板**（v2 加）— 教务 / 校长视角
3. （A 数据归属：弱，因老师离职率低，列入待验）

### 产品矩阵协同（多产品采购溢价）

> 飞象 AI 是一组产品（作业 / 作文 / 知识库 / ...），**知识库可独立售卖**，但买得越多协同越强。

| 学校采购组合 | 体验 |
|---|---|
| 仅知识库 | **完整可用**，AI 基于老师自己的资料工作 |
| 知识库 + 作业 | AI 对话可 **@引用** 学情数据；知识库出的题可"发到作业"布置 |
| 知识库 + 作文 | AI 对话可 **@引用** 学生作文 / 批改记录 |
| 全套 | 飞象 AI 拥有该老师跨场景的全部 context，"懂老师"程度最高 |

**关键纪律**（来自 §3.3）：
- 学情 / 作文等数据 **不进入知识库**，只作为 AI 临时 sources 引用
- 不强制学校"必须买全套" — 单买知识库就完整可用
- 多产品打通是**加分**，不是**前置条件**

## §5 · 不做什么（最重要的一节）

### 🚫 永不做（红线，写进文档抗诱惑）

1. **AI 主动推送 / 修改原文件** — 违反 §3.1
2. **AI 给"建议你..."** — 违反 §3.2，给数据不给指令
3. **AI 自主出题 / 备课**（不需老师触发） — 违反 §3.2
4. **AI 自动评分 / 取代教师** — 教育权属老师
5. **Podcast / 音频概览**（NotebookLM 招牌） — 中国老师不听 podcast 备课
6. **插件市场 / 第三方扩展** — 不做平台化
7. **教师社区 / 公开互助 / 教研圈** — 伪需求，类似产品都死了
8. **课堂直播 / 监控** — 不监控老师
9. **AI 自动生成"文件夹总结" / "主题 wiki 页" / "知识盘点"** — 违反 §3.2；老师是"复用者"不是"创造者"，没有"梳理我自己知识体系"的需求；且烧 token 没价值
10. **文件级 AI 摘要卡片**（每个文件挂一张 AI 写的解读） — 同上；老师打开文件就是为了看文件本身，不需要 AI 替她"读"
11. **把 LLM Wiki 模式作为产品形态展示给老师** — Wiki 是技术实现细节（如果团队选择跑这个架构），但永远只在后台；老师永远只看到自己的文件 + AI 对话的成品输出

### ⏳ v1 不做（v2/v3 看情况）

- 实时多人协作编辑（v2 做"教研组一起出题"具体场景）
- 学情大屏 / 校长看板
- 校本知识库 / 区域知识库的完整协同
- 老师手动公开分享（v2 通过"贡献到校本/区域"实现，不做 feed/社区）

## §6 · v1 范围 vs v2 路径

### v1 必做（聚焦 — 把"单老师场景"做透）

- 拖文件夹 / 压缩包 / 单文件上传（含进度反馈）
- 老师建文件夹（AI 不强制结构化，但提供文件夹基础）
- AI 生成（基于知识库）：4 个高频场景全覆盖
- **AI 产物一步入库**：AI 在对话中产出 → 老师点「保存到我的知识库」 → 直接进对应文件夹（v3 删除"草稿"中间态；没保存的产物从「最近对话」找回）
- OCR（含手写，复用飞象星球能力）— 加低置信度兜底 UI
- 检索 + 问答（基于知识库）
- 入门指南（产品预置的第 1 条对话，挂在「最近对话」顶部）
- **「我的题库」一级实体**（与"我的知识库"、"最近对话"并列）
  - 单题集合，按学科 / 知识点 / 题型 / 难度多维筛选
  - 与「飞象作业星 · 我的资源」共用同一份数据
  - 入题三种途径：① 老师手动新增（用得少）② 上传题目图片（走 OCR）③ 文件预览页「AI 录入题库」（主路径）
  - AI 对话可通过 Function Call 调用题库（"出 5 道二次函数中等难度题"）
- **左栏导航 — 3 个一级实体（顺序固定）**：我的知识库 → 我的题库 → 最近对话（知识图谱降级到左下角"工具栏"位置，仅宣传向，不抢戏）

### v1 不做但**架构必须留口子**

| 口子 | 现在留法 |
|---|---|
| 校本知识库 / 区域知识库 | 左栏命名「我的知识库」（已留），未来加第 2、3 个 group |
| 多人 / 角色权限 | 用户表 `role` 字段、文件表 `visibility` 字段 |
| 学校 / 区县域 ID | 数据隔离基础（账号体系预留） |
| 学情看板入口 | 顶栏菜单里给"管理员视角"留位置但不做 |
| 跨产品账号体系 | 飞象统一 ID（SSO 接入预留） |
| **外部 sources 引用接口** | AI 对话可临时调用作业/作文产品数据，**不写入知识库** |
| 知识库内容外发接口 | 草稿能"发到作业产品布置作业"占位入口 |

### v2 必做

- **教研组共享 + 共建**：一个老师上传的资料、写的草稿，能被同组其他老师看到、引用、共建
- 这是 V1-A → V1-B 的延伸；不是先做花架子的协同功能再寄希望于把单老师做好（顺序错了产品就死了）

## §7 · 假设清单（每个判断都标注是事实还是信念）

> 这节最重要的价值：v1 上线后被打脸时，知道**到底是哪条假设错了**。

### ✓ 有依据（已验证）

- **A1** PLG 链路：飞象签过的学校采购案例支撑
- **A3** 老师典型上传规模 50-500 份资料
- **A4** 老师能写出有效 prompt（飞象 AI 助手 / 作文批改老师真实数据支撑）

### ⚠️ 强直觉（没数据但相信，v1 上线必须验证）

- **A2** "AI 生成的内容能直接用"——v1 上线后必须验证 AI 产物的"保存到我的知识库"转化率（旧称草稿采纳率）
- **A6** "通用 AI 不够用，老师会切飞象"——作文批改场景已部分验证"专业 > 通用"，但知识库场景需再验
- **A8** "知识库" 老师能秒懂——产品经理觉得自然，但没问过老师
- **A9** 学校会同时采购多个飞象产品 → 矩阵协同的"溢价"真实存在——需 v1 上线后通过销售数据验证（多产品采购率 / 客单价提升率）
- **A10**（2026-04-30 新增）**老师不需要"AI 帮我读懂资料"** — 老师是结果导向（出题/教案/课件成品），不会主动消费"文件夹总结" / "wiki 主题页" / "知识地图"等中间产物。指引产品形态：AI 对老师隐藏中间过程，只输出成品。**验证方式**：v1 上线后观察"知识图谱"页面访问率 < 5% 即支持此判断
- **A11**（2026-04-30 新增）**老师对"题"和"文件"有不同心智** — 找文件按时间/章节，找题按知识点/难度/题型。所以题库需要独立入口（不是文件管理器的某个 view）。**验证方式**：上线后观察题库的独立访问率、AI 对话中"调题"vs"调文件"的比例

### 🚨 真不确定 + 高风险（v1 上线 2 周内必须验证）

- **A5（v3 已化解）** 老师可能不懂"草稿 lifecycle" 心智  
  → **化解方式**：v3 直接删除"草稿"概念，改为「最近对话」+「保存到我的知识库」一步入库。无 lifecycle 可学  
  → 上线后观察：AI 产物保存率、保存动作的平均耗时
- **A7** 学校在意"老师离职带走资料"——老师离职率低，痛点弱，可能 B 端付费驱动 A 项要砍

## §8 · 失败信号（投降条件）

> 一年内出现以下任一信号，承认产品方向错了，**严重警告 + 产品方向重审**。

| 信号类型 | 量化标准 |
|---|---|
| **行为**（主） | 100 个试用老师，**2 周后 < 30%** 每周打开 ≥1 次 |
| **价值** | AI 产物的**「保存到我的知识库」转化率 < 20%** |
| **商业** | 12 个月内**没有 1 个学校**愿意付 ≥¥3000 的企业版 |
| **差异化** | **≥ 50% 老师反馈"还不如我自己用豆包/Kimi"** |
