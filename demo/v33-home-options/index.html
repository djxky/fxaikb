ChatGPT / Claude
01
ChatGPT 极简（纯 A）
主区超大留白 + 中央对话框。侧栏保留完整资产入口（知识库 / 班级 / 应用）。形态最熟悉、上手成本最低，最像 ChatGPT。
✓ A 生成承接最强 ✓ 学习成本最低 ✗ B 浏览靠侧栏二级 ✗ 跟 ChatGPT 太像
极端 A（对话兜底一切） 打开方案 1 →
飞象老师 c 端形态
02
对话 + 内容流（A + B）
顶部对话框（A）+ 来源 tabs（推荐 / 学校知识库 / 教研沉淀 / 应用广场 / 我的应用）+ 4 列瀑布流。资料和应用统一卡片语言，老师按 tab 切换浏览。滑下去对话框缩成底部悬浮条，tabs 吸顶。
✓ 视觉最像飞象老师 c 端 ✓ B 浏览体验最佳 ✓ 应用 / 资料统一卡片语言 ✗ C 用应用要切 tab，权重弱
A + B（C 进 tab） 打开方案 2 →
★ 推荐｜对应"老师刚才在干嘛"
03
任务接续：对话 + 最近任务 + 内容流
在方案 2 基础上，对话框下方加一层「最近」任务卡：刚扫的作业、待批的作文、正在进行的测验、待发布的草稿。只放事实，不预测——回应飞象作业/作文已经验证过的"老师扫了，回首页就该看见"。
✓ 接续手头活，扫了就看见 ✓ 任务卡只放事实，零踩雷 ✓ 兜底入口卡承接新老师空状态 ✗ 比方案 2 多一段，首屏更密
= 方案 2 + 最近任务层 打开方案 3 →
